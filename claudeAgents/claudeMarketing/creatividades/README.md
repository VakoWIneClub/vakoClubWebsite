# Creatividades

Posts, reels, guiones, calendarios y anuncios de `vako-creatividades`, principalmente para Instagram (@vakoclub), con extensiones a TikTok/YouTube y ads.

**Convención de nombre:** `AAAA-MM-DD-nombre-pieza.md` (pieza individual) o `AAAA-MM-DD-calendario-semanal.md` (lote/calendario)

El estado de la campaña de Instagram de 3 meses se sigue en `../01-ESTADO-ACTUAL.md` (sección "📅 Campaña de Instagram").

# Ofertas

Ofertas, precios, bundles y promociones diseñadas por `vako-ofertas`: lanzamientos de guías, bundles con tienda/suscripción, promos estacionales.

**Convención de nombre:** `AAAA-MM-DD-nombre-oferta.md`

La oferta vigente siempre está resumida en `../01-ESTADO-ACTUAL.md` (sección "🎯 Oferta activa") — `vako-landing`, `vako-email` y `vako-creatividades` parten de ahí para saber qué están vendiendo.
